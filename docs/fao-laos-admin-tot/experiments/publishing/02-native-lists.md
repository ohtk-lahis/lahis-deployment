# ทดลองการจัดรูปแบบ LAHIS

## ภาษาไทยและระยะห่าง

ผู้รายงานบันทึกข้อมูลหมู่บ้าน แล้วเจ้าหน้าที่ตรวจสอบรายงานบน Dashboard

น้ำ ผู้ฝึกสอน เจ้าหน้าที่ พื้นที่ ข้อมูล ป่วย ถัดไป ย้อนกลับ

## ขั้นตอนชุดที่หนึ่ง

1. เปิดรายการรายงาน

2. ตรวจชื่อหมู่บ้านและข้อมูลเหตุการณ์

## ขั้นตอนชุดที่สอง

1. เปิดรายการผู้ใช้

2. ตรวจบทบาทและขอบเขตพื้นที่ของเจ้าหน้าที่ก่อนเริ่มปฏิบัติงาน เพื่อให้แน่ใจว่ามองเห็นหมู่บ้านที่ตนเองรับผิดชอบและสามารถติดตามรายงานได้อย่างถูกต้อง

## ข้อควรตรวจ

- ผู้รายงานเห็นความคิดเห็นที่ส่งกลับมาจากเจ้าหน้าที่

- ข้อความรายการนี้ตั้งใจให้ยาวมากกว่าหนึ่งบรรทัด เพื่อทดสอบว่าบรรทัดที่สองเยื้องตรงกับข้อความของบรรทัดแรก และไม่ย้อนกลับไปอยู่ใต้เครื่องหมายหัวข้อ
