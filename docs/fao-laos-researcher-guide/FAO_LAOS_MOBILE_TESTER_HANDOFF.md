# Mobile Tester Handoff — FAO Laos / LAHIS Staging

เอกสารสั้นสำหรับผู้ทดสอบ LAHIS Mobile: ทำตามลำดับ 5 งานด้านล่างและบันทึกผลที่พบ ใช้ข้อมูลจำลองเท่านั้น

## 1. เตรียมก่อนเริ่ม

- ติดตั้งและเปิด LAHIS Mobile
- ที่หน้า Login ตรวจว่าแสดง `เซิร์ฟเวอร์: LAHIS Demo` หากไม่ใช่ให้กด `เปลี่ยน`
- ขอรหัสเชิญ Reporter 7 หลักและชื่อหมู่บ้านทดสอบจากผู้ประสานงาน
- เตรียม Username ใหม่ที่ไม่ซ้ำ และใช้อีเมลตัวอย่าง เช่น `mobile.test@example.com`
- จดรุ่นแอป รุ่นโทรศัพท์ ระบบปฏิบัติการ และเวลาเริ่มทดสอบ

ผลที่ต้องได้: Mobile เชื่อมกับ `LAHIS Demo` และมีรหัสเชิญที่ผูกกับหมู่บ้านทดสอบ

## 2. ลงทะเบียน Reporter และยอมรับ Consent

1. กด `ลงทะเบียนเป็นผู้รายงาน`
2. กรอกรหัสเชิญ 7 หลัก แล้วกด `ถัดไป`
3. ตรวจว่า Authority และหมู่บ้านตรงกับที่ผู้ประสานงานแจ้ง หากไม่ตรงให้หยุดทดสอบ
4. กรอกข้อมูล Reporter ด้วยข้อมูลจำลอง
5. กด `Read privacy notice` อ่านแล้วกด `I have read the terms`
6. เลือก `I accept the terms and agreement`
7. กด `สร้างบัญชีและเข้าระบบ`

ผลที่ต้องได้: แอป Login ด้วย Reporter ใหม่และเปิดหน้า Home โดยไม่เกิด error

## 3. ส่งรายงาน Animal Sick/Death

1. กด `+ รายงานใหม่` แล้วเลือก `Animal Sick/Death`
2. กรอกข้อมูลจำลอง ตัวอย่าง: Cattle, Breeding adult, Male/Female, Unknown Disease, Diarrhea
3. กรอกจำนวน: 1 ครัวเรือน, สัตว์ 10, ป่วย 2, ตาย 1, ฟื้นตัว 0
4. กด `ตรวจสอบ` ตรวจสรุป แล้วเลือก `I confirm that the information provided is accurate`
5. กด `ส่งรายงาน`

ผลที่ต้องได้: รายงานใหม่แสดงเป็นรายการล่าสุดบน Mobile และรายละเอียดตรงกับค่าที่กรอก

## 4. เพิ่ม Follow-up และตรวจ AI feedback

1. เปิดรายงานที่เพิ่งส่ง แล้วจดยอด `Totals (report + follow-ups)` ก่อนเพิ่มข้อมูล
2. กด `+ ติดตามผล` และกรอกเฉพาะจำนวนที่เพิ่ม เช่น ครัวเรือน +1, สัตว์ +2, ป่วย +1, ตาย +0, ฟื้นตัว +1
3. ตรวจสรุป ยืนยันความถูกต้อง และกด `ส่งการติดตาม`
4. กลับไปตรวจว่ายอดรวมสะสมเท่ากับยอดเดิมบวก Follow-up และแท็บ `การติดตาม` มีรายการใหม่
5. เปิดแท็บ `ความคิดเห็น` ตรวจว่าผล AI ปรากฏในรายงานเดิม หากยังไม่มาให้รอสักครู่แล้วเปิดรายงานใหม่

ผลที่ต้องได้: Follow-up ไม่สร้างรายงานใหม่ ยอดสะสมถูกต้อง และ AI feedback ผูกกับรายงานเดิม

ข้อควรจำ: ผล AI เป็นข้อมูลประกอบเบื้องต้น ไม่ใช่คำวินิจฉัยโรค

## 5. บันทึก Animal Census และส่งผลทดสอบ

1. เลือกแท็บ `สำมะโน` แล้วตรวจชื่อหมู่บ้านและ Authority
2. เลือก `สำมะโนสัตว์` และตรวจ Round `DEMO_ANIMAL_2026`
3. จดค่าปัจจุบันก่อนแก้ไข จากนั้นกรอกจำนวนครัวเรือนและจำนวนสัตว์ด้วยค่าที่ทีมกำหนด
4. ตรวจค่าทั้งหมด แล้วกด `บันทึกสำมะโนปีปัจจุบัน`
5. เปิดหน้าเดิมอีกครั้งและตรวจว่าค่าล่าสุดถูกบันทึก

ผลที่ต้องได้: ข้อมูล Census ล่าสุดของหมู่บ้านแสดงถูกต้องใน Round เดิม

### Checklist ส่งมอบผล

- [ ] เลือก Server `LAHIS Demo`
- [ ] ลงทะเบียน Reporter และ Consent สำเร็จ
- [ ] ส่ง Animal Sick/Death สำเร็จ
- [ ] Follow-up และยอดรวมสะสมถูกต้อง
- [ ] ตรวจ AI feedback ในแท็บความคิดเห็น
- [ ] บันทึก Animal Census สำเร็จ
